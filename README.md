# RenewalPath prototype

Open `index.html` directly in a browser, or push these four files to a GitHub repository and enable **Settings → Pages → Deploy from a branch** (select `main` and `/root`). No build configuration is needed.

All data, records, acknowledgments, OTP verification, and status updates are fictional mock behavior. Browser `localStorage` acts as the local mock backend; no government service or external API is contacted, and documents are checked locally only.

No document contents are stored: only the selected filename is retained for the active demo. This static client-side prototype applies input validation, output escaping, local-only persistence, and limited data storage. It is not a production security system and must not be used with real personal data.
